# PCAP Screenshot Checklist

| Screenshot title | Side | Page/component | Action | Must appear | Suggested caption | Why useful |
|---|---|---|---|---|---|---|
| PCAP Analyzer Upload Panel | User | `PcapAnalyzerPage` | Open `/pcap-analyzer` before upload | File input, confidence mode, max alerts/clusters, Include Zeek, Analyze button | PCAP upload and analysis configuration screen | Shows user entry point |
| Invalid File Type Validation | User | `PcapAnalyzerPage` | Select non-PCAP file | Error message for invalid type | PCAP file validation feedback | Demonstrates safe upload restrictions |
| Running Analysis Progress | User | `PcapAnalyzerPage` | Start valid analysis | Progress bar, job ID, status, message, Cancel button | Background PCAP analysis progress | Shows async job workflow |
| Cancel Analysis | User | `PcapAnalyzerPage` | Cancel queued/running job | Cancelled status/message | PCAP job cancellation state | Shows cancellation support |
| Completed Summary | User | `PcapAnalyzerPage` | Wait for done job | Security score, total flows, alerts, suspicious, risk level | PCAP analysis summary after completion | High-level result view |
| Severity Breakdown | User | `SeverityBreakdownCard` | View completed report | Severity chart/card | Severity distribution generated from PCAP report | Visualizes alert severity |
| Threat Breakdown | User | `ThreatBreakdownCard` | View completed report | Top attack types/chart | Top detected PCAP attack categories | Visualizes labels/classes |
| Risk Per IP | User | `RiskPerIpCard` | View completed report with findings | IP, role, threat count, top severity/risk | Risk per IP generated by PCAP analysis | Supports per-host risk explanation |
| Attack Clusters Table | User | `PcapAnalyzerPage` | Scroll to clusters | Severity, attack type, source/destination, count, confidence | Clustered PCAP threat patterns | Shows grouping logic |
| Alerts Drilldown Table | User | `PcapAnalyzerPage` | Scroll to alerts | Time, source/destination, port, label, confidence, severity, decision, reason | Flow-level PCAP alerts with rationale | Shows evidence-backed detections |
| Alert Detail Drawer | User | `PcapAnalyzerPage` | Click an alert row | Reasoning/evidence/raw JSON tabs or detail view | Detailed PCAP alert evidence | Shows analyst review workflow |
| Timeline Chart/Table | User | `PcapAnalyzerPage` | View timeline section | Time-based activity/results | PCAP event timeline | Shows temporal evidence |
| Job History Modal | User | `PcapAnalyzerPage` | Open history | Recent jobs, status, report/evidence availability | PCAP job history | Shows persistence/history |
| Report Export | User | `PcapAnalyzerPage` | Click report export on completed job | Download/report button available | Exportable PCAP JSON report | Shows artifact export |
| Evidence Export | User | `PcapAnalyzerPage` | Click evidence export on job with evidence | Evidence ZIP action or unavailable message | PCAP evidence export availability | Shows optional evidence bundle |
| Dashboard Network Security Score | User | `DashboardPage` / `NetworkSecurityScoreCard` | Open dashboard after completed PCAP | Network Security Score, recent PCAP posture | Dashboard PCAP-derived network score | Shows dashboard integration |
| Recent Security Alerts | User | `RecentSecurityAlertsPanel` | Open dashboard after alerts | PCAP alert cards and clear button | Recent PCAP alerts in dashboard | Shows alert feed integration |
| Admin PCAP Overview Metrics | Admin | `PcapAnalysisAdminControl` | Open admin PCAP section | Uploaded files, jobs, running/completed/failed, avg time | Admin PCAP operations overview | Shows monitoring |
| Admin Queue Health | Admin | `PcapAnalysisAdminControl` | View queue card | Queue health, queued/running/failed/completed | PCAP queue health monitoring | Shows operational status |
| Admin Latest Results | Admin | `PcapAnalysisAdminControl` | View latest results table | filename, status, risk score/level, mode, Zeek, actions | Latest PCAP analysis jobs | Shows admin job inspection |
| Admin Report Preview | Admin | `PcapAnalysisAdminControl` | Click preview report | JSON preview modal/panel | Admin PCAP report preview | Shows admin evidence access |
| Admin Evidence Export | Admin | `PcapAnalysisAdminControl` | Export evidence for eligible job | Evidence export action/toast | Admin PCAP evidence bundle export | Shows admin export control |
